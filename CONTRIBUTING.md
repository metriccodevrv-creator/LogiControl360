# Contribuir a LogiControl360

## Flujo sugerido

1. Crear una rama `feature/*` o `fix/*`.
2. Ejecutar `npm install`.
3. Verificar `npm run lint`, `npm run typecheck` y `npm run build`.
4. Documentar cambios relevantes en `CHANGELOG.md`.

## Estándares

- TypeScript estricto.
- Textos visibles en español.
- Sin secretos reales en el repositorio.
- Validaciones en cliente y servidor para formularios críticos.
